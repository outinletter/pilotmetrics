# 데이터 재감수 결과 및 수정 계획

재감수 기준일: 2026-09-14

재감수는 원본 `events`를 변경하지 않고 `event_quality_review`와 분석용 뷰를 기준으로 수행했다.

## 확인 결과

- 전체 원본 사건: 38,206건
- 원본 샘플 데이터: 15건
- 상업용 제트 자동 적격 후보: 12,508건
- 중복 URL 및 날짜 검토를 제외한 우선 분석 코호트: 10,765건
- 기종·운항 근거 재검토: 25,622건
- ARAIB 날짜 검토: 55건
- 기상값 검토: 22,702건
- 기존 `aircraft_category='JET'`와 실제 기종명이 충돌하는 후보: 904건

## 감수에서 확인한 오류

1. TSB와 ASN의 `aircraft_category='JET'`는 실제 기종 검증값으로 사용할 수 없다. Balloon, DHC-8, GA-8 Airvan 같은 비제트 기체가 JET로 표시된 사례가 확인됐다.
2. `weather_summary`에 국가·지역명이 저장된 사례가 많다. 이는 기상자료가 아니므로 기상 변수로 사용하면 안 된다.
3. ARAIB 영문 55건은 게시일과 사고일이 혼재되어 있다. 사고일이 원문에서 확인되지 않는 항목은 날짜 분석에 포함하지 않는다.
4. TSB는 기종 결측이 11,232건이다. 운항 유형만으로 상업용 제트로 확정하지 않는다.
5. ASN·NTSB에는 기종명이 명확한 항목과 category만 존재하는 항목이 섞여 있다. category만으로 적격 판정을 내리지 않는다.

## 수정 순서

### 1단계: 즉시 적용 완료

- `event_quality_review`에 출처별 적격성·결측·중복 플래그를 저장했다.
- `commercial_jet_analysis_events`와 `commercial_jet_verified_events`를 분리했다.
- 샘플 데이터는 분석에서 제외했다.
- 날짜 미확정 ARAIB 자료는 별도 검토 상태로 분리했다.
- 중복 URL 행을 표시했다.

### 2단계: 상업용 제트 판정 정정

- 기종명에 Boeing, Airbus, Embraer, Bombardier, CRJ, 737, 777, 787, A320, A330, A350 등이 있으면 제트 후보로 인정한다.
- 일본어·한국어 기종명 사전을 추가한다.
- `aircraft_category='JET'`만 있는 항목은 자동 적격에서 제외한다.
- Part 121/129는 보조 근거로 사용하며, Part 번호만으로 제트라고 판단하지 않는다.
- 904건의 category·기종 충돌을 우선 검토한다.

### 3단계: 원문 보강

- TSB 공개 Aircraft 테이블과 Occurrence 테이블을 occurrence key로 조인한다.
- ASN 원문 기종명과 운항 유형을 재추출한다.
- NTSB `avall.zip` 공식 대량자료를 확보해 CAROL 누락분을 보강한다.
- ARAIB·JTSB 상세보고서에서 기종·운영자·사고일·보고서 상태를 보강한다.

### 4단계: 기상·시간 정정

- 국가·지역명으로 채워진 `weather_summary`는 분석에서 제외한다.
- METAR/TAF 또는 조사보고서에 근거가 있을 때만 기상 필드를 채운다.
- 현지시각과 UTC를 구분하고, 시간대가 없으면 UTC를 생성하지 않는다.
- 시각 결측은 0값으로 대체하지 않는다.

### 5단계: 중복·사건 통합

- 동일 URL 중복을 보고서 중복과 사고 중복으로 나눈다.
- 공식 사건번호를 우선 키로 사용한다.
- 날짜+공항만으로 병합하지 않는다.
- 예비보고서·최종보고서·번역본은 출처 레코드로 보존하고 사건 연결 테이블에서 관계를 관리한다.

### 6단계: 최종 분석 승인

최종 분석 코호트에 포함하려면 다음 조건을 모두 만족해야 한다.

- 기종이 제트임을 원문 또는 공식 구조화 필드에서 확인
- 상업운항 근거가 있거나, 사용자가 허용한 공식 제트 기종 목록으로 확인
- 사고일이 확인됨
- 중복 URL 검토 대상이 아님
- 출처 URL·수집시각·원문 해시가 존재
- 결측값과 추정값의 상태가 구분됨

현재 우선 분석 코호트는 10,765건이지만, 904건의 기종 충돌 및 ASN·TSB의 고정 JET 값 재검증 후 최종 숫자를 확정해야 한다.

## 검증 방법

재감수 후 자동 보정 결과:

- 명백한 비제트 기종과 충돌하는 기존 \`JET\` 분류 990건을 분석 뷰에서 제외하고 근거를 저장했다.
- ARAIB 상세 원문에서 사고일·게시일이 모두 확인된 5건을 보정 뷰에 연결했다.
- 국가명이 기상값으로 들어간 행은 원본을 유지하면서 최종 보정 뷰에서 제외했다.
- 중복 URL·날짜 검토·샘플 데이터는 최종 보정 뷰에서 제외했다.
- 보정 후 우선 분석 코호트: **8,959건**.

보정은 \`event_corrections\`에 기록되며 원본 \`events\`는 변경하지 않았다. 이 8,959건은 자동 보정 결과이고, 기종 원문이 없는 TSB·ASN 자료는 추가 원문 감수 전까지 포함하지 않는다.

수정 후 다음을 다시 실행한다.

```powershell
npx wrangler d1 execute pilot-briefing --remote --command "SELECT * FROM commercial_jet_verified_events LIMIT 10;"
npx tsc --noEmit
node --test worker/tests/research.test.mjs
uv run --with requests --with beautifulsoup4 python -m unittest discover -s tests -v
```

원본 `events` 건수 38,206건이 변하지 않는지 확인하고, 적격 코호트 건수·출처별 결측률·중복 행 수를 전후 비교한다.
